# Usage

```python
import statistics_dashboard
```

Each module is self-contained; see docstrings for the API:

- `statistics_dashboard.app` — Main application entry point
- `statistics_dashboard.core` — Core functionality for distribution fitting and hypothesis tests
- `statistics_dashboard.dashboard` — Curses dashboard implementation with panels and sparklines
- `statistics_dashboard.models` — Data models and structures used throughout the application
- `statistics_dashboard.tests_test_core` — Unit tests for core functionality
- `statistics_dashboard.utils` — Utility functions used across the application
